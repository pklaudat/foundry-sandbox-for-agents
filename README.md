# Foundry Sandbox for Agents

A baseline framework for building AI agents with integrated Azure services, optimized for learning with minimal security and cost considerations. The main goal of this codebase is to provide basic setup for the Microsoft Agents League.

## Overview

This repository provides foundational modules to rapidly prototype and deploy intelligent agents powered by Azure AI services. It emphasizes accessibility for learners while maintaining essential security practices.

## Features

- **Agent Framework**: Modular architecture for hosting AI Agents
- **Azure AI Foundry Integration**: Pre-configured connectors for Azure OpenAI, Cognitive Services, and Azure Cosmos DB
- **Cost-Optimized**: Starter configurations for development and learning environments
- **Security Baseline**: Essential security patterns without over-engineering

## Getting Started

### Prerequisites

- Python 3.9+
- Azure subscription
- Azure Cosmos DB Emulator (optional, for local development)

### Installation

```bash
git clone github.com/pklaudat/foundry-sandbox-for-agents.git
cd foundry-sandbox-for-agents
```
